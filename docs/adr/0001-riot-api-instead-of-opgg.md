# 0001 — 用 Riot 官方 API 而非爬取 op.gg

## 狀態
已採納（2026-11-14）

## 背景
原始需求是「到 op.gg 或其他合法網頁查詢戰績」。op.gg 沒有公開 API，要在 app 內呈現其資料只能爬取內部端點，違反其使用條款、易因改版失效、可能被封 IP。op.gg 的資料本身即來自 Riot API。

## 決定
戰績一律透過 Riot 官方 API（帳號、召喚師、match-v5）取得；op.gg 只作為「一鍵開啟多人查詢頁」的外部連結。

為了在免費開發 Key 的限速（20 次/秒、100 次/2 分鐘）內於數秒完成一次稽查：
- 每人只取最近 15 場（5 人 ≈ 90 次請求）；
- 同一場對戰在一次稽查內只查一次；
- **不做跨稽查的本機快取**（使用者明確要求）。

## 取捨
- 放棄每人 20 場與跨次快取，換取單次稽查約 5 秒內完成。
- 每位使用者需自備 Riot API Key，app 不內建任何 Key。
